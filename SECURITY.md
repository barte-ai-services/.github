# Política de Segurança

Software proprietário da Barte Soluções de Pagamento LTDA (ver LICENSE).

## Reportar uma vulnerabilidade
Não abra issue pública. Use o canal privado de security advisories do GitHub
("Report a vulnerability") ou contate o time de segurança da Barte diretamente.
Inclua: componente afetado, impacto, passos de reprodução e versão.
