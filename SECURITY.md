# Política de Segurança

Software proprietário da Barte Soluções de Pagamento LTDA (ver `LICENSE`).

## Reportar uma vulnerabilidade

Não abra issue, pull request nem discussão pública. Use o reporte privado de vulnerabilidade do GitHub neste repositório: **Security › Report a vulnerability**, em <https://github.com/barte-ai-services/.github/security>. Ele vale para qualquer sistema da Barte AI Services.

Inclua o componente afetado, o impacto, os passos para reproduzir e a versão ou o commit.

A página completa: [segurança](https://barte-ai-services.github.io/.github/community/security/). Os princípios de segurança da engenharia: [segurança antes de meta](https://barte-ai-services.github.io/.github/how-we-work/security/).
