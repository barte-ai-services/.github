# Política de Segurança

Software proprietário da Barte Soluções de Pagamento LTDA (ver LICENSE).

## Reportar uma vulnerabilidade

Não abra issue pública. Use o reporte privado do GitHub ("Report a vulnerability") no repositório afetado, ou contate o time de segurança da Barte diretamente. Inclua o componente afetado, o impacto, os passos de reprodução e a versão.

A política completa, e os princípios de segurança da engenharia: [segurança](https://barte-ai-services.github.io/.github/community/security/).
