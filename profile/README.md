# Barte AI Services

Plataforma de IA agêntica da Barte — extensível, orientada a contratos e hiperpersonalizável.

Repositórios-núcleo: gatekeeper (edge/proxy), loom (orquestração), chronicle (dados),
tessera (identidade/Keycloak), shell (UI), guild (framework de agentes).

Padrões da org (labels, templates, workflows reutilizáveis) vivem neste repositório `.github`.
