Este é o handbook de engenharia da **Barte AI Services**, o time da Barte que constrói a Barte AI Platform. Ele diz como o time trabalha e quais padrões os sistemas seguem. A fonte é o repositório [`barte-ai-services/.github`](https://github.com/barte-ai-services/.github), e o site é gerado a partir dele.

## O handbook é público

O repositório e o site são públicos. Por isso, o que entra e o que fica de fora segue uma regra só:

| Entra | Fica de fora |
| --- | --- |
| Os princípios e o jeito de trabalhar | Nomes, IDs e localização de contas AWS |
| Os padrões de API, dados, workflows e configuração | Nomes de variáveis e de segredos de um sistema específico |
| Os nomes de tecnologia do Tech Radar | Hostnames internos e o endereço de cada instalação |
| Os nomes dos repositórios públicos | O escopo de testes de intrusão |
| Padrões genéricos, como `BARTE_<OWNER>_<NAME>` | Os nomes das organizações que a Barte atende |

Na dúvida, fica de fora. Um repositório público não guarda detalhe interno de operação: a menor exposição vale também para informação.

## O código é proprietário

Ser público não torna o conteúdo livre. Este repositório e o código da Barte AI Services são software proprietário da **Barte Soluções de Pagamento LTDA**, com todos os direitos reservados, nos termos do [`LICENSE`](https://github.com/barte-ai-services/.github/blob/main/LICENSE). A maior parte dos repositórios da organização no GitHub é privada.
