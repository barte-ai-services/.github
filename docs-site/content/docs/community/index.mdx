Esta aba reúne o que vale para quem contribui com o código da **Barte AI Services**, o time que constrói a Barte AI Platform: como contribuir, como nos comportamos, como decidimos, e como tratamos compliance e segurança.

O código da Barte é proprietário e a maior parte dos repositórios da organização é privada. Este handbook é público: ele descreve **como** trabalhamos, nunca o que está dentro dos sistemas.
