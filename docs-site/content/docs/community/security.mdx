O software da Barte AI Services é proprietário da **Barte Soluções de Pagamento LTDA**. Esta página diz como reportar uma vulnerabilidade nele. Os princípios de segurança da engenharia estão em [segurança antes de meta](/how-we-work/security).

## Nunca em público

<Callout type="error" title="Nada de issue pública">
  Não abra uma issue, um pull request nem uma discussão pública sobre uma vulnerabilidade. Um relato público expõe o problema antes da correção.
</Callout>

## Como reportar

O canal é o **reporte privado de vulnerabilidade do GitHub**, no repositório `barte-ai-services/.github`. Ele vale para qualquer sistema da Barte AI Services, inclusive os de repositório privado.

<Steps>
  <Step>
    Abra [github.com/barte-ai-services/.github/security](https://github.com/barte-ai-services/.github/security).
  </Step>
  <Step>
    Clique em **Report a vulnerability**.
  </Step>
  <Step>
    Preencha o formulário e envie.
  </Step>
</Steps>

Inclua no relato:

- o componente ou o sistema afetado;
- o que a vulnerabilidade permite, e o impacto;
- os passos para reproduzir;
- a versão, a data ou o commit em que você observou o problema.

O relato fica visível só para você e para quem administra a segurança do repositório na Barte AI Services. A conversa segue no próprio aviso privado, até a correção.
