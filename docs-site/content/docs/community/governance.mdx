Esta página diz onde cada decisão da Barte AI Services fica escrita e como ela é tomada. Uma regra que não está no handbook nem num ADR ainda não é regra.

## Onde cada coisa fica escrita

| O quê | Onde | Como muda |
| --- | --- | --- |
| Regras que valem em todos os repositórios | Este handbook, no repositório `barte-ai-services/.github` | Por pull request a este repositório |
| Decisões de um repositório | Um ADR em `docs/architecture/decisions/` do repositório | Por um ADR novo, que substitui o anterior |
| Planos de trabalho | Uma issue de plano | Pela própria issue, antes de construir |

## Planos

Um trabalho que pede mais de um PR começa num **plano**, numa issue de plano. O plano diz as peças, a ordem, os critérios de aceite e as decisões tomadas, com a base de cada uma. Só depois de aprovado o trabalho começa ([issues](/how-we-work/issues)).

## ADRs

Toda decisão técnica que alguém vai questionar depois vira um **ADR**, no repositório que ela afeta:

- **O arquivo** é `docs/architecture/decisions/NNNN-<slug>.md`, com o número em quatro dígitos e o slug em inglês, kebab-case.
- **A citação** é `ADR-NNNN`, no texto, nos commits e no código.
- **O ADR entra por pull request**, como qualquer código.
- **Um ADR aceito não é editado para mudar a decisão.** Uma decisão nova vem num ADR novo, que diz qual substitui; o antigo passa a substituído e aponta para o novo. Os dois continuam legíveis.

O formato do ADR está em [documentação](/how-we-work/documentation).

## O handbook e os ADRs de um repositório

O handbook é o padrão. Em conflito, **o handbook vence, exceto onde um ADR do próprio repositório diz o contrário**. Esse ADR diz o que muda e por quê.

Uma regra que passa a valer para mais de um repositório deixa de ser ADR local e vira um pull request neste handbook.

## Como decidimos

1. **Qualquer pessoa do time propõe**, numa issue, num plano ou num pull request.
2. **Quem está na mudança busca o consenso**, ouvindo as perspectivas diferentes. Depois de decidido, o time se compromete com a decisão, inclusive quem defendeu outro caminho.
3. **Sem consenso, a decisão sobe para a liderança da Barte AI Services**, que decide.
4. **A decisão fica escrita**: no plano, num ADR ou neste handbook.
