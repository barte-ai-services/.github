## Cobertura

**O `check` exige pelo menos 70% das linhas e 65% dos branches.** Abaixo disso, o `check` falha, e o `ci` junto.

## Todo repositório

- **`make check` é o mesmo que o CI.** Ele passa antes do commit. Um passo que roda no CI e não roda no `make check`, ou o contrário, é defeito.
- **`deploy/compose/compose.yml` sobe o desenvolvimento local**, com as dependências do componente na forma da instalação.

## A forma de um módulo

| Pasta | O que mora nela |
|---|---|
| `apps/` | O que atende: API, MCP, tela |
| `workers/` | O que trabalha: os workers do Workflow Manager, um por domínio |
| `packages/` | O que os dois usam, incluindo `observability`, `config` e `secrets` |
| `deploy/terraform/aws` | O módulo Terraform do componente |
| `deploy/compose` | O desenvolvimento local |

**A dependência só desce.** Um pacote nunca importa um deployável, e um deployável nunca importa outro. O que dois compartilham vira pacote.
