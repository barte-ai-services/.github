---
title: Catálogo
description: Todo code de erro da plataforma, com o status HTTP, a mensagem e quando acontece.
---

A mensagem é o `title` do problem. A tabela é a lista fechada: um erro que não cabe em nenhum `code` daqui pede uma linha nova neste catálogo antes de existir no código.

| code | HTTP | Mensagem | Quando |
|---|---|---|---|
| `bad_request` | 400 | Pedido malformado. | Corpo, parâmetro ou cabeçalho inválido |
| `invalid_body` | 400 | O corpo não é JSON, ou não é um objeto JSON. | Corpo ilegível |
| `invalid_parameter` | 400 | `<nome>` deve ser `<tipo>`. | Parâmetro com tipo errado |
| `bad_cursor` | 400 | O cursor não é válido. Peça a primeira página de novo. | `after` de outra rota ou de outro filtro |
| `invalid_idempotency_key` | 400 | `Idempotency-Key` vai de 1 a 128 caracteres. | Chave vazia ou longa |
| `unauthorized` | 401 | Sem token, ou token de outro emissor ou de outra audiência. | Com `WWW-Authenticate: Bearer resource_metadata=…` |
| `forbidden` | 403 | A pessoa não tem o papel. | Nenhum papel permitido, ou `root` |
| `not_found` | 404 | Não existe nesta instalação. | Recurso inexistente ou fora do alcance da pessoa |
| `method_not_allowed` | 405 | Método não permitido. | Com `Allow` |
| `conflict` | 409 | Conflito de estado. | Ação incompatível com o estado atual |
| `request_too_large` | 413 | O pedido passa do tamanho aceito. | Corpo acima do limite |
| `idempotency_key_reused` | 422 | Esta `Idempotency-Key` já foi usada com outro corpo. | Mesma chave, corpo diferente |
| `refused` | 422 | Campo recusado. | Campo inválido; com `errors[]` |
| `upstream_not_provisioned` | 424 | O provedor ainda não está conectado nesta instalação. | Conector sem credencial |
| `upstream_not_configured` | 424 | O conector não está configurado nesta instalação. | Rota sem upstream |
| `rate_limited` | 429 | Limite de uso atingido. Espere o tempo do Retry-After e repita. | Cota; com `Retry-After` e `RateLimit*` |
| `internal` | 500 | Erro interno. | Exceção não tratada |
| `upstream_error` | 502 | O componente de trás ou o provedor falhou. | Erro do provedor, sem o corpo dele |
| `upstream_unreachable` | 502 | O provedor não respondeu. | Falha de conexão |
| `redirect_not_allowed` | 502 | O provedor respondeu com um redirecionamento, que não seguimos. | 3xx do provedor |
| `upstream_response_too_large` | 502 | A resposta do provedor passa do tamanho aceito. | Resposta acima do limite |
| `upstream_not_minimizable` | 502 | A resposta do provedor não pôde ser reduzida com segurança. | Minimização impossível |
| `unavailable` | 503 | Indisponível. | Estado compartilhado fora do ar |
| `login_unavailable` | 503 | O login está indisponível agora. | Sem emissor |
| `upstream_timeout` | 504 | O provedor demorou demais para responder. | Timeout do provedor |

## As recusas do MCP

As recusas que só existem no MCP entram nestes códigos, e não ganham código próprio:

| Recusa do MCP | code |
|---|---|
| A ferramenta precisa do token da pessoa, e a chamada não o trouxe | `unauthorized` |
| A consulta passa do limite de linhas | `refused` |
| A visão ainda não tem `observed_through` | `conflict` |
| O grafo dos dados não está ligado na instalação | `unavailable` |
