# Contribuindo

- **Commits/PRs:** Conventional Commits (`feat|fix|chore|docs|refactor|test|perf|build|ci`).
- **Issues:** use os templates; o tipo é o Issue Type nativo (Task/Bug/Feature/Enhancement/
  Initiative/Epic-Milestone/Plan/Spike).
- **Labels:** padronizadas via `.github/labels.yml` (sync automático) — não crie label solta.
- **Código:** inglês, autoexplicativo, testes ao lado (`*.test.*`), sem segredo no código.
- **Contratos:** mudança de API/schema/env sem quebra, ou documentada e versionada.
